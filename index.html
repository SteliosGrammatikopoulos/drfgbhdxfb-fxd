Σύνδεση με το Google Apps Script. Αν η σελίδα σερβίρεται μέσα από το Apps Script (google.script.run), δεν χρειάζεται τίποτα εδώ. Σε κάθε άλλη περίπτωση επικολλήστε το URL του Web App (τελειώνει σε /exec) από: Ανάπτυξη → Νέα ανάπτυξη → Web app.
❓ Οδηγίες εγκατάστασης & αντιμετώπιση προβλημάτων

1) Απαιτήσεις

  • Προγράμματα περιήγησης: Chrome ή Edge (το Firefox δεν υποστηρίζει το Web Speech API).
  • Η σελίδα πρέπει να τρέχει σε https:// ή localhost για να δίνεται η άδεια μικροφώνου.

2) Άδεια μικροφώνου

  • Πατήστε 🎤 και όταν ο browser ρωτήσει, επιλέξτε «Να επιτρέπεται».
  • Αν το αρνηθήκατε κατά λάθος: κλικ στο εικονίδιο δίπλα στη διεύθυνση → Μικρόφωνο → Να επιτρέπεται → ανανέωση σελίδας.

3) Γιατί βλέπω «προεπισκόπηση» του εγγράφου;

  • Η Google δεν επιτρέπει την ενσωμάτωση της σελίδας /edit σε iframe. Η σελίδα φορτώνει αυτόματα τη μορφή /preview του ίδιου εγγράφου.
  • Για να φαίνεται το έγγραφο: Κοινή χρήση → Γενικά → «Όποιος έχει τον σύνδεσμο» → Θεατής.
  • Το κουμπί «↗ Άνοιγμα για επεξεργασία» ανοίγει το κανονικό /edit σε νέα καρτέλα.

4) Ρύθμιση Apps Script (ώστε το κείμενο να μπαίνει στο έγγραφο)

  1. Ανοίξτε το έγγραφο → Επεκτάσεις → Apps Script.
  2. Επικολλήστε τον κώδικα του αρχείου Code.gs στο αρχείο Code.gs.
  3. (Προαιρετικά, για να σερβίρεται και η ίδια η σελίδα από το Apps Script:) προσθέστε αρχείο HTML με όνομα index (περιεχόμενο: αυτό το index.html) και αρχείο HTML με όνομα script (περιεχόμενο: το script.js).
  4. Ανάπτυξη → Νέα ανάπτυξη → Τύπος: Web app → Εκτέλεση ως: Εμένα → Πρόσβαση: Όλοι → αντιγράψτε το URL που τελειώνει σε /exec.
  5. Επικολλήστε το URL στα ⚙ Ρυθμίσεις εδώ → Αποθήκευση → 🔍 Δοκιμή σύνδεσης. Στην πρώτη χρήση η Google θα ζητήσει εξουσιοδότηση (Review permissions) — αποδεχτείτε την.
  6. ⚠️ Μετά από κάθε αλλαγή στον κώδικα: Ανάπτυξη → Διαχείριση αναπτύξεων → ✏️ → Έκδοση: Νέα έκδοση → Ανάπτυξη.

5) Φωνητικές εντολές (ελληνικά)

  • «νέα γραμμή», «νέα παράγραφος», «σημείο», «κόμμα», «ερωτηματικό», «θαυμαστικό», «άνω τελεία», «διαγραφή όλων».

6) Σημειώσεις

  • Η αναγνώριση φωνής του Chrome γίνεται μέσω των διακομιστών της Google — απαιτείται σύνδεση internet.
  • Κάθε αποστολή γράφει το κείμενο ως νέα παράγραφο στο τέλος του εγγράφου.
  • Εναλλακτικά χωρίς Apps Script: 📋 Αντιγραφή και επικόλληση (Ctrl+V) μέσα στο έγγραφο.
